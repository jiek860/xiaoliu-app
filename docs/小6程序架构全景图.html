功能运行流程

聊天主链路 + 后台闭环
1用户输入（发送 / 回车）
2电脑控制快速通道
computer_controller.try_handle 命中则直接执行返回，不进入 LLM
3上下文组装（5 路注入）
向量检索（记忆 top_k=3） 情景记忆（时间戳） 知识图谱（rag_query） 联网搜索（关键词命中→深度搜索） 工具调用（算/查/读→LLM 选工具）
4LLM 生成（流式输出）
人格提示 + 反思建议 + 历史对话 → 本地 xiao6-7b（日常）；云端已失效走本地路由；聊天活跃 120s 内后台让路
5群聊组合（并行 15s 超时）
小七 编程 · 小八 分析 · 小九 策划 —— 独立人设只补充自己领域，超时跳过不拖主回复
6代码沙盒验证
写代码意图 + 回复含 python 代码块 → staging 隔离试跑（8s 超时），运行成功/失败 + 输出附在回复后
7存记忆 → 回复用户
向量 + 知识图谱 + 历史，同步入库存档
8后台闭环（_bg · 聊天 120s 内全让路）
自评估（规则，不占模型） 反思 每5轮（LLM 打分 → 注入下次） 记忆卡 / 记忆闭环（空闲才做） 技能沉淀（任务类成功→SKILL） 群聊评估
9定时后台（不阻塞聊天）
连续学习 20 分钟/轮（聊天时暂停） 自愈闭环 4h（有错才动） 记忆复习 30min 模型巡检 10min 热更新 5min 自动检测
