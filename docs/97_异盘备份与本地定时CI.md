# 异盘备份与本地定时 CI（v25.2.33 / 2026-10-27）

> 对应优化清单 P2-9（备份异盘）与 P2-12（本地定时 CI）。
> 两个脚本都在 `scripts/`，不依赖网络、不进打包产物。

## 1. 异盘备份：`scripts/backup_offsite.py`

### 为什么

原来只有项目目录里的 `backups/`（自动更新自己建的）。备份和源码在**同一块盘**上 ——
盘坏、误删、勒索加密，两边一起没。

### 目标盘怎么定（重要）

**不能写死 `D:\网盘`**。本机实测：

| 盘 | 状态 |
|---|---|
| C: | 系统盘，剩余 10.6 GB |
| D: | **Windows 安装介质（只读、0 空闲）**，写进去直接 `PermissionError` |
| E: | 项目所在盘（`E:\xiaoliu`） |

所以脚本按这个顺序找目标：

1. `--dest` 参数
2. 环境变量 `X6_OFFSITE_BACKUP`
3. `data/config.json` 的 `"备份异盘目录"`
4. **自动挑选**：从 D: 往后找「可写、剩余 > 200 MB、且不是项目所在盘」的盘；
   盘上有 `网盘 / OneDrive / 坚果云 / 百度网盘 / WPS网盘` 目录就放进其下，
   否则放到 `<盘>:\xiao6-backup`

找不到第二块盘时**明确报错并给三种办法**，不会静默写到同盘。
目标与项目同盘默认拒绝（`--allow-same-drive` 仅供自测）。

### 用法

```bat
py -3 scripts\backup_offsite.py --dry-run     :: 只算体积，不写盘
py -3 scripts\backup_offsite.py               :: 真复制
py -3 scripts\backup_offsite.py --keep 6      :: 保留最近 6 份（默认 4）
py -3 scripts\backup_offsite.py --dest "F:\bak"
```

### 备份内容

- 代码：`core gui modules modules_repo plugin_repo tools scripts docs templates config`
- 数据：`data/`（排除可再生的 `browsers`(718MB) / `datasets` / `swebench` /
  `workspace_index` / `logs` / `cache`）
- 根目录启动文件：`run.py run_server.py build_release.py xiao6.spec
  config.default.json requirements.txt pyproject.toml CHANGELOG.md README.md`
- 快照目录名 `xiao6_YYYYMMDD_HHMM`，里面带 `backup_manifest.json`
  （时间、文件数、字节数、版本号）

体积实测：**1353 个文件 / 26.4 MB / 约 1 秒**（本地同盘自测）。
恢复：把快照目录下的 `core/gui/modules/data/...` 拷回项目对应位置即可。

### 每周自动跑（Windows 计划任务）

```bat
schtasks /Create /TN "xiao6-异盘备份" /SC WEEKLY /D SUN /ST 12:00 ^
  /TR "\"C:\Windows\py.exe\" -3 \"E:\xiaoliu\scripts\backup_offsite.py\""
schtasks /Query /TN "xiao6-异盘备份" /V /FO LIST
schtasks /Delete /TN "xiao6-异盘备份" /F
```

> ⚠️ 计划任务里必须写**绝对路径**（工作目录默认是 `C:\Windows\System32`）。

## 2. 本地定时 CI：`scripts/ci_local.py`

### 为什么不用 GitHub Actions

本机 `github.com:443` 直连被 RST，Actions 的触发与回看都不稳。先做
「本地定时脚本 + 结果落 docs」，等网络可用再把同一套命令搬上云端。

### 跑什么（14 项）

语法编译 / 版本号 / 按钮清单 / 工具清单 / 线程生命周期 / 静默异常 / 依赖形状 /
文件长度 / 插件仓库一致 / 插件质量 / 插件安全 / 插件签名 / 类型与风格 / 全量测试。

```bat
py -3 scripts\ci_local.py            :: 全套（约 5~6 分钟）
py -3 scripts\ci_local.py --quick    :: 跳过 pytest 与类型检查（约 1 分钟）
py -3 scripts\ci_local.py --no-record
```

结果追加到 [`docs/96_本地CI运行记录.md`](96_本地CI运行记录.md)：

```
| 时间 | 结果 | 通过/总数 | 耗时 | 失败项 |
```

退出码：`0` 全过；`1` 有失败项（计划任务里可直接看上次结果码）。

### 每天自动跑

```bat
schtasks /Create /TN "xiao6-本地CI" /SC DAILY /ST 03:00 ^
  /TR "\"C:\Windows\py.exe\" -3 \"E:\xiaoliu\scripts\ci_local.py\""
```

## 3. 与发布流程的关系

- `ci_local.py` 的**插件仓库一致 / 插件签名**两项与 `tools/check_repo_sync.py`
  等价：改完 `modules/installed` 必须
  `tools/rebuild_modules_repo.py --apply` → `tools/sign_modules.py`，
  否则这两项会红（实测本轮就是靠它抓到「忘了重新签名」）。
- 自动更新的质量闸（P2-10）复用同一批门禁：
  部署前 `pre_commit_check.py --full`，部署后 `pre_commit_check.py` + 冒烟 pytest；
  任一失败就不部署 / 回滚。
