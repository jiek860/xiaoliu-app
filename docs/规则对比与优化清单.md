## C. 建议新增 / 优化的规则

| # | 规则 | 现状 | 建议 |
|---|---|---|---|
| C1 | **LLM 路由置信度** | 关键词≥2 直走 / 否则 LLM，无置信度字段 | 给 LLM 结果加置信度（让 LLM 输出 0-1），低于阈值（如 0.6）→ 主 LLM 兜底，不硬路由 |
| C2 | **情景记忆直接接线** | 只经记忆闭环 run 间接记录 | 在 `_bg` 里直接调 `remember_scene`，避免依赖记忆闭环被禁用时情景记忆断线 |
| C3 | **技能沉淀加"确认有用"** | 仅触发词+回答正常就捕获 | 增加用户反馈门：回答后用户点"有用"才沉淀 SKILL，防垃圾技能堆积 |
| C4 | **电脑控制安全白名单** | try_handle 在主流程最前 | 补规则：非白名单命令（删文件/写系统目录/关机）必须 `trunk.confirm` 弹窗；未确认不执行 |
| C5 | **top_k 参数统一** | trunk=3 / 默认=5 / 记忆闭环=3 | 统一为配置项 `retrieval.top_k`，一处改全局生效 |
| C6 | **自愈 apply 落点** | verify 后 apply 未明确"应用什么" | 明确：apply = 用修复方案改目标模块文件（先备份）→ hot_reload → 失败回滚；或仅标记已修复（不真改代码）二选一写清楚 |
| C7 | **群聊模式开关传播** | 仅 group_chat/group_loop 用 config 群聊模式 | 让开关同时控制群聊组合、异常评估、子智能体参与，统一入口 |
| C8 | **嵌入请求节流** | 每次向量 search 都调 Ollama embedding | 短时间重复查询走缓存；embedding 请求加 200ms 最小间隔，避免拖慢回复 |
