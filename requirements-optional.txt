#  按需安装，不装也能启动，只是对应功能用不了。
#
#  两种装法：
#    A. 装进系统 Python（会全局生效）
#         py -3 -m pip install -r requirements-optional.txt
#    B. 装进项目的 optional_libs\（推荐，不污染系统环境；程序会自动加载）
#         py -3 -m pip install --target optional_libs -r requirements-optional.txt
#       或直接双击 scripts\install_optional.bat
#       也可以打开程序里的「功能扩展组件」窗口逐个点安装。
#
#  程序启动时会把 optional_libs\ 和 libs\ 都加进 sys.path（见 run.py）。
# ============================================================

# ⚠️ av 必须锁在 19 以下：
#    faster-whisper 1.2.1 里 faster_whisper/audio.py 调用
#        av.open(path, mode="r", metadata_errors="ignore")
#    而 PyAV 19 把这个参数去掉了，装 av>=19 会直接报
#        TypeError: open() got an unexpected keyword argument 'metadata_errors'
#    它的依赖声明只写了 av>=11，所以 pip 不会拦，必须自己锁。
