小6智能体 - 模型教程（Ollama）
════════════════════════════════════════════════════════════

小6智能体需要Ollama来运行本地AI模型。

一、什么是Ollama？
Ollama是一个本地运行大模型的工具，
让您的电脑能离线运行AI。

二、下载Ollama

官网地址（多备份）：
1. 官网：https://ollama.com/download
2. 国内镜像：https://ollama.com.cn/
3. GitHub：https://github.com/ollama/ollama/releases

三、安装Ollama

1. 双击安装包
2. 一路下一步
3. 安装完会自动启动
4. 右下角会有Ollama图标

四、下载模型

1. 打开cmd
2. 输入以下命令下载模型：

   # 小模型（快）
   ollama pull qwen2.5:3b

   # 大模型（好）
   ollama pull qwen2.5:7b

   # 嵌入模型（记忆用）
   ollama pull nomic-embed-text

3. 等待下载完成（几个GB，耐心等）

五、验证模型

1. 输入：
   ollama list

2. 应该能看到下载的模型

3. 测试对话：
   ollama run qwen2.5:3b
   输入：你好
   看有没有回复

六、配置小6

1. 打开小6智能体
2. 进设置
3. 确认模型地址是：
   http://localhost:11434
4. 选模型：qwen2.5:3b 或 qwen2.5:7b

════════════════════════════════════════════════════════════

常见问题：

Q: Ollama下载慢？
A: 用国内镜像地址下载

Q: 模型下载慢？
A: 开代理，或者用小模型（3b）

Q: 提示"Ollama未启动"？
A: 右下角看有没有Ollama图标，没有就重启

Q: 回复很慢？
A: 用小模型（3b），7b需要更好的显卡
