小6智能体 - 模型教程（Ollama）
════════════════════════════════════════════════════════════

小6智能体需要Ollama来运行本地AI模型。

一、什么是Ollama？
Ollama是一个本地运行大模型的工具，
让您的电脑能离线运行AI。

二、下载Ollama

官网地址（多备份）：
1. 官网：https://ollama.com/download
2. 国内镜像：https://ollama.com.cn/
3. GitHub：https://github.com/ollama/ollama/releases

三、安装Ollama

1. 双击安装包
2. 一路下一步
3. 安装完会自动启动
4. 右下角会有Ollama图标

四、下载模型

1. 打开cmd
2. 输入以下命令下载模型：

   # 小模型（快）
   ollama pull qwen2.5:3b

   # 大模型（好）
   ollama pull qwen2.5:7b

   # 嵌入模型（记忆用）
   ollama pull nomic-embed-text

3. 等待下载完成（几个GB，耐心等）

五、验证模型

1. 输入：
   ollama list

2. 应该能看到下载的模型

3. 测试对话：
   ollama run qwen2.5:3b
   输入：你好
   看有没有回复

六、配置小6

1. 打开小6智能体
2. 进设置
3. 确认模型地址是：
   http://localhost:11434
4. 选模型：qwen2.5:3b 或 qwen2.5:7b

七、云端模型接入（2026-10-20 新增）
────────────────────────────────────────────────────────────
设置 → 模型 → 配置云端模型，支持：

  · OpenAI
  · Anthropic（Claude）
  · Google Gemini
  · OpenRouter
  · Azure OpenAI
  · LM Studio（本地 OpenAI 兼容）
  · llama.cpp server
  · vLLM
  · 自定义 / OpenAI 兼容

服务商下拉框会自动带出默认地址和模型名；Azure 还要填
deployment（模型框）和 API version。LM Studio/llama.cpp/vLLM
一般不需要 API Key。

八、模型能力与自动路由
────────────────────────────────────────────────────────────
程序会按任务需求检查：

  · tool calling
  · JSON mode
  · vision 视觉
  · context window 长上下文

本地模型满足要求时优先本地；本地失败、离线或能力不足时自动
走云端兜底。未知模型按保守能力处理，不会假设它支持视觉或工具。

九、用量和成本
────────────────────────────────────────────────────────────
Ctrl+K 搜「用量成本」或「模型用量」：

  · 最近 7 天调用次数
  · Token 总量
  · 估算成本
  · P50/P95 延迟
  · 按模型分组

价格是估算值，可在 data\config.json 里用 model_prices 覆盖。
未知模型显示 $0，不会伪造费用。

════════════════════════════════════════════════════════════

常见问题：

Q: Ollama下载慢？
A: 用国内镜像地址下载

Q: 模型下载慢？
A: 开代理，或者用小模型（3b）

Q: 提示"Ollama未启动"？
A: 右下角看有没有Ollama图标，没有就重启

Q: 回复很慢？
A: 用小模型（3b），7b需要更好的显卡
