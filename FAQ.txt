【安装问题】

Q1: 程序打不开，一闪就没了？
A: 打开"打开控制台.bat"，看错误信息。
   一般是缺依赖，pip install 一下就行。

Q2: 提示"缺少PyQt5"？
A: 打开cmd，输入：pip install PyQt5

Q3: 提示"缺少cryptography"？
A: 打开cmd，输入：pip install cryptography

【模型问题】

Q4: 提示"Ollama未启动"？
A: 看右下角有没有Ollama图标。
   没有就去 https://ollama.com 下载安装。

Q5: AI回复很慢？
A: 1. 用小模型（3b），不要用7b
   2. 关掉其他占内存的程序
   3. 第一次回复慢是正常的，模型在加载

Q6: AI回复"本地模型错误"？
A: 1. 检查Ollama有没有启动
   2. 检查模型有没有下载
   3. 进设置里换个模型试试

Q7: 怎么下载更多模型？
A: 打开cmd，输入：ollama pull 模型名
   比如：ollama pull qwen2.5:3b

【使用问题】

Q8: 聊天记录存在哪？
A: E:\xiaoliu\data\chats.db
   是SQLite数据库，可以用工具打开看。

Q9: 怎么清空聊天记录？
A: 点侧边栏的"清空聊天"按钮。

Q10: 怎么换账号？
A: 点功能中心里的"登录"按钮，换个账号登录。

Q11: 激活码忘了怎么办？

Q12: 怎么备份？
A: 复制整个 data 文件夹就行。
   或者用功能中心里的"备份"功能。

【功能问题】

Q13: 代码编辑器怎么用？
A: 点"+"号，选"放入代码编辑器"。
   AI给的代码会自动放进编辑器里。

Q14: 语音输入怎么用？
A: 点输入框旁边的麦克风按钮。
   需要先装语音识别组件。

Q15: 联网搜索怎么用？
A: 直接问问题就行，AI会自动判断要不要搜索。
