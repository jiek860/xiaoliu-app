小6智能体 - 常见问题 FAQ
============================================================

【安装问题】

Q1: 程序打不开，一闪就没了？
A: 双击「打开控制台.bat」，看窗口里的报错。
   多半是缺依赖  重新双击 install.bat 即可。

Q2: 提示「缺少 PyQt5 / cryptography / psutil」？
A: 重新双击 install.bat（它会走清华镜像装齐 5 个核心依赖）。
   不想用 bat 也可以手动跑：
     py -3 -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

Q3: pip 装得很慢 / 像卡住了？
A: 一定要带国内源：-i https://pypi.tuna.tsinghua.edu.cn/simple
   （install.bat 已经带上了）

【模型问题】

Q4: 提示「Ollama 未启动」？
A: 看右下角有没有 Ollama 小羊驼图标；没有就去 https://ollama.com 下载安装。

Q5: AI 回复很慢？
A: 1) 用小模型（3b），别用 7b   2) 关掉占内存的程序   3) 首次回复慢是模型在加载

Q6: 提示「本地模型错误」？
A: 1) 确认 Ollama 在跑   2) 确认模型已下载   3) 设置里换个模型试试

Q7: 怎么下载更多模型？
A: 命令行执行：ollama pull 模型名（例如 ollama pull qwen2.5:3b）

【使用问题】

Q8: 聊天记录存在哪？
A: data/chats.db（SQLite），可以用工具打开看。

Q9: 怎么清空聊天记录？
A: 左侧栏的「清空聊天」按钮。

Q10: 怎么换账号？
A: 左侧栏「登录」按钮。

Q11: 激活码忘了怎么办？
A: 联系开发者：851294943@qq.com

Q12: 怎么备份？
A: 程序会自动备份到 backups/；也可以复制整个 data/ 文件夹。

【功能问题】

Q13: 代码编辑器怎么用？
A: 底部「代码编辑器」按钮；AI 给的代码可以一键送进去。

Q14: 语音输入怎么用？
A: 底部「语音输入」按钮（需要先装语音组件，见 设置 → 系统 → 可选组件）。

Q15: 联网搜索怎么用？
A: 直接问就行，它会自己判断要不要搜。

Q16: 有哪些功能？找不到入口？
A: 按 Ctrl+K 打开命令面板，输入关键词搜（能力 + 面板都在里面）。
   也可以看 设置 → 系统 → 新手教程。

【其他问题】

Q17: 程序崩溃了怎么办？
A: 崩溃/闪退会自动上报（脱敏摘要，不含聊天内容）。
   你也可以手动到 设置 → 系统 → 意见反馈 里留言。

Q18: 怎么反馈问题？
A: 设置 → 系统 → 意见反馈（或 Ctrl+K 搜「反馈」）。
   别再发邮件了  反馈通道已经改成飞书群机器人。

Q19: 有新版本怎么更新？
A: 设置 → 系统 → 检查更新（会先验签再比版本）。

【第二阶段功能（2026-10-20 新增）】

Q20: 云端模型怎么选服务商？
A: 设置 → 模型 → 配置云端模型 → 服务商下拉框。
   支持 OpenAI、Anthropic、Gemini、OpenRouter、Azure OpenAI、
   LM Studio、llama.cpp、vLLM 和自定义 OpenAI 兼容接口。
   地址和模型会自动带出；Azure 还需 deployment 和 API version。

Q21: 本地模型失败会自动切云端吗？
A: 会。程序按 tool calling、JSON、vision、上下文长度判断能力；
   本地离线、失败或能力不足时走云端兜底。未知模型按保守能力处理。

Q22: 哪里看 Token 和费用？
A: Ctrl+K 搜「用量成本」或「模型用量」。
   看最近 7 天调用、Token、估算成本、P50/P95 延迟。
   未知模型显示 $0；价格可在 data\config.json 的 model_prices 里覆盖。

Q23: RAG 知识库在哪里？
A: Ctrl+K 搜「RAG管理」。
   可导入文件/目录、设置 ACL 角色、检索并查看引用页码和 offset、
   删除来源索引。文件内容没变时会跳过重复索引。

Q24: 团队/多用户怎么用？
A: Ctrl+K 搜「团队管理」或「多用户」。
   支持 owner/admin/editor/viewer/auditor；登录账号会绑定团队角色；
   管理员禁用账号后不能登录；集中配置保存到 data\team\central_config.json；
   审计可脱敏导出为 JSON。

Q25: 插件怎么更新和回滚？
A: 插件市场 → 检查更新。只列出与宿主版本和插件 API 兼容的版本；
   可一键全部更新，更新前自动保留回滚副本；单个插件卡片可回滚。
   远程插件默认关闭，开启后仍要求 HTTPS + 主机白名单 + RSA 签名。

Q26: 电脑 Agent 失败时能看到原因吗？
A: 会。重试事件会显示修复计划（刷新界面、滚动、切换定位源、等待、
   请求用户），trace 中有动作、验证结果、重试次数和修复原因。

【界面问题】

Q: 头像点开为什么只有几个按钮？
A: 头像菜单固定 5 项：切换模式、检查更新、设置、登录/切换账号、帮助。
   其他功能在高级模式的「更多」菜单里，按任务/资料/工具/安全/插件-MCP/开发分组。

Q: 左侧「模块」下面的按钮看不到 / 不知道有没有显示完？
A: 左侧栏现在可以上下滚动，模块标题会显示「模块（N）」。
   当前可用的模块按钮数量就是 N；没有模块时会显示「暂无模块按钮」。

Q: 为什么简单模式没有「更多」？
A: 简单模式只保留高频入口；点头像  切换模式进入高级模式后，
   「更多」按钮才会出现，里面收纳其他功能。

Q: 收到「上次异常退出，自动补报」，但程序明明没崩？
A: 旧版补报逻辑存在误报，已修复：现在会先读取上一次的运行标记、
   检查 pid 是否还活着，再决定是否补报。更新到当前版本后重启即可。

【兼容性与升级】

Q: 支持哪些 Windows 和 Python？
A: Windows 10 / 11 是主支持环境；Windows Server 部分可用；
   Windows 7 / 8 不建议。Python 支持 3.10 / 3.11 / 3.12；
   3.9 及以下不支持，3.13 尚未验证。

Q: macOS / Linux 能直接用吗？
A: 聊天和部分文件功能可能可用，但电脑控制、窗口操作、截图、剪贴板、
   桌面 Agent 等核心能力基本不可用，不是当前支持目标。

Q: 升级后旧聊天记录/记忆会丢吗？
A: 启动时会检查 data/_schema.json，旧数据先备份到 data/_migrations/，
   再按 v0 -> v1 -> v2 逐级迁移。迁移失败不会静默覆盖原文件；
   到 设置 -> 系统 -> 深度自检和 data/logs/trunk.log 看原因。

Q: 插件为什么装不上？
A: 新版插件要求 RSA 签名和兼容的 api_version（当前 1.0）。
   第三方插件还不能 import core 私有模块；违规包会在安装前被静态检查拒绝。
   手动改过 modules/installed/ 的话，需要重新 rebuild + sign。
