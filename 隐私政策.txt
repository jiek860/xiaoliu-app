小6智能体（以下简称"本软件"）由开发者独立开发并维护。
我们非常重视您的隐私。本隐私政策说明本软件如何收集、使用、
存储和保护您的数据。

请您在使用本软件前仔细阅读本政策。您点击"同意"按钮，即表示
您已阅读、理解并同意本政策全部内容。

════════════════════════════════════════════════════════════════
一、我们收集哪些数据
════════════════════════════════════════════════════════════════

1.1 本地存储的数据（不上传）
  - 聊天记录（含您与AI的对话内容）
  - 配置设置（模型选择、界面设置、功能开关）
  - 账号名与激活码（加密存储）
  - 记忆数据（向量库、知识图谱、遗忘曲线）
  - 上传的文件（图片、PDF、Word、文本）
  - 语音录音（用于语音识别，识别后本地保留）
  - 截图（电脑控制功能的截图）
  - 日志文件（运行日志、错误日志）
  - 更新历史与备份

1.2 可能上传到第三方服务的数据
  - 云端模型：如果您启用"云端模型"模式，您的对话内容会发送
    到您配置的云端API（如智谱、通义、DeepSeek等）。
  - 联网搜索：如果您启用"联网"功能，您的搜索关键词会发送到
    搜索引擎。
  - 模型下载：从Ollama官网、GitHub等下载模型时会请求对应服务器。

1.3 我们不会上传的数据
  - ❌ 您的完整聊天记录（除非您主动启用云端模型）
  - ❌ 您的文件内容（除非您主动发送给云端模型）
  - ❌ 您的账号密码（本软件无密码登录）
  - ❌ 您的浏览历史、键盘记录
  - ❌ 您的使用行为统计（无埋点、无遥测）

1.4 崩溃日志
  - 程序崩溃时会写入本地日志文件
  - 崩溃日志仅包含：错误类型、错误信息、时间戳、调用栈
  - 崩溃 / 闪退时，程序会**自动**向开发者指定的群机器人发送一份脱敏摘要：
    系统信息（操作系统 / Python 版本 / 小6 版本 / 线程数 / 时间）、
    最近的错误行、崩溃现场（调用栈）、以及日志文件的路径
  - 摘要不包含：聊天内容、您的文件、账号、任何密钥（发送前自动脱敏）
  - Python 层异常当场发送；原生崩溃由**看门狗子进程**当场补发；若看门狗也没能存活，则在下次启动时补发
  - 如不需要，可在 config.json 里设 "auto_report_crash": false 关闭

════════════════════════════════════════════════════════════════1.5 本地安全与运行数据（不上传）
  - 工具权限规则、网络访问事件、审计日志
  - 任务状态、步骤时间线、trace
  - 模型 token / 耗时 / 费用统计
  - 工作区目录
  这些数据用于安全审计、任务恢复和用量统计，默认只保存在本机
  data\ 目录；敏感字段会脱敏，不记录完整请求体、密码和 Token。


二、数据存储位置与期限
════════════════════════════════════════════════════════════════

2.1 存储位置
  所有本地数据存储在您的电脑上 data\ 目录

2.2 存储期限
  - 数据保留在您的电脑上，直到您主动删除
  - 日志文件默认保留最近10MB，自动轮转
  - 安全审计、trace、用量数据可按配置保留天数清理
  - 备份默认保留最近2-5份，旧的自动清理
  - 卸载本软件后，data\目录不会自动删除，需您手动删除

════════════════════════════════════════════════════════════════
三、数据如何使用
════════════════════════════════════════════════════════════════

3.1 本地使用
  - 让AI记住您说过的话（记忆系统）
  - 改进AI的回答质量（知识图谱、向量检索）
  - 保存您的配置（模型、界面、功能开关）
  - 支持账号隔离（不同账号数据独立）

3.2 我们不会做
  - ❌ 把您的数据卖给第三方
  - ❌ 用您的数据做广告
  - ❌ 未经您同意上传您的数据

════════════════════════════════════════════════════════════════
四、您的权利
════════════════════════════════════════════════════════════════

4.1 查看
  您可以随时打开data\目录查看所有数据文件

4.2 导出
  - 日志中心 → 导出日志包
  - 聊天记录 → 导出聊天记录

4.3 删除
  - 删除单个会话：会话列表 → 右键 → 删除
  - 清空聊天记录：侧边栏 → 清空按钮
  - 删除安全审计/任务/trace/用量：删除 data\security、data\task_runtime、data\traces、data\usage
  - 删除全部数据：删除data\目录

4.4 撤回同意
  - 您可以随时卸载本软件并删除data\目录

════════════════════════════════════════════════════════════════
五、数据安全
════════════════════════════════════════════════════════════════

5.1 本地存储：SQLite数据库 + 加密存储 + DPAPI 保护敏感配置
5.2 传输安全：云端模型 HTTPS + 更新 SHA256 + RSA 签名 + 插件签名
5.3 执行安全：工具权限确认、默认拒绝、代码沙箱、紧急停止
5.4 网络安全：出站网络策略，默认拦截私有地址、元数据地址和 file://
5.5 数据完整性：原子写 + WAL模式
