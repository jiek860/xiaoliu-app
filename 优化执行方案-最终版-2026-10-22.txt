  事后很难分辨"哪次是 AI 改的"。stash 快照可回退，更安全。

第六部分  GitHub Actions CI 精简（并行做，约半天）
================================================================================

  背景：main 分支保护当前要求 8 个 required check，每次 PR 跑 9 个 runner。
  核心约束：required check 不出现 = 永远等待 = PR 合不进去。

  6.1  分支保护 required 从 8 减到 4：
         保留：static / test / ci-required / codeql-analyze
         移除：compat-required / windows-build-required /
               portable-required / security-required

  6.2  各 workflow on: 改动：
         test.yml              不变（push + PR）
         codeql.yml            不变
         compat-matrix.yml     push: branches: [main] + workflow_dispatch
         build-windows.yml     push: branches: [main] + tags: ['v*'] +
                               workflow_dispatch（保留 paths 过滤）
         build-portable.yml    同上
         security.yml          每周一 + push: paths: requirements*.txt/lock +
                               workflow_dispatch
         perf.yml / release.yml  不动

  6.3  预期：
         PR 阶段：只跑 test + codeql，约 5 分钟
         合并 main：后台跑 compat + build + security，不等人
         打 tag：完整打包 + 签名 + release

  6.4  执行后必跑：
         tools/check_workflow_security.py
         同步更新 docs/CI_RELEASE_GATES.md
