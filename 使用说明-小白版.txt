【小6智能体 · 小白使用说明】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一、这是什么？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一个住在你电脑里的 AI 助手。跟别的 AI 不一样的地方：

  · 记忆是自己的     聊过的事它记在本地文件里，重启不丢，
                     而且是"卡片式"的 —— 能翻能改能删
  · 脑子可以本地的   装个 Ollama 就完全离线可用，不联网也能聊
  · 能动手            不只是聊天：能开浏览器、操作窗口、跑代码、
                     读写文件、看图片、听你说话
  · 数据全在本地     聊天记录、记忆、配置都在 data\ 目录，
                     不上传任何地方（除非你主动用云端模型）
                     ※ 唯一例外：崩溃/闪退时会自动发一份**脱敏摘要**
                       （系统信息 + 错误行 + 调用栈 + 日志路径，不含聊天内容），
                       可在 config.json 里用 auto_report_crash 关掉

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
二、怎么打开？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  方法1：双击「启动PyQt.bat」
  方法2：在文件夹里打开命令行，输入
            py -3 run.py

  系统与 Python：
     Windows 10 / 11：主支持环境
     Python 3.10 / 3.11 / 3.12：支持（CI 会跑 Windows 兼容矩阵）
     Python 3.13、Windows 7/8：未验证 / 不建议
     macOS / Linux：聊天和部分文件功能可能可用，
      但电脑控制、窗口操作、截图等桌面能力不是当前支持目标

  第一次打开如果出现登录框：
     已有账号：输入账号名，点「登录」
     第一次使用：点「激活」，输入激活码后完成登录
     登录后如果弹出「首次设置向导」，花一分钟配好模型就能用了

  配完之后想再看：设置  帮助  首次设置向导（简单模式）
                或：设置  系统  首次设置向导（高级模式）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
三、配模型（这是唯一必须做的一步）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
两条路，选一条就行。向导里都有，跟着点。

【路线A：本地 Ollama（免费，推荐，断网也能用）】
  1. 首次向导里点「⬇️ 一键下载 Ollama 安装包」
     · 约 1.5GB。程序会**自动挑国内加速源**，实测比官网快 100 倍以上
       （官网直链实测 0.05 MB/s，下完要 8 小时；加速源实测 6~18 MB/s，几分钟）
     · 有进度条，会显示速度和剩余时间；下不动可以点「取消下载」
  2. 下完按钮会变成「📦 立即安装」，点它，按弹出的安装向导点完
     · 装到哪个盘可以自己选（按提示改）
  3. 装完 Ollama 会自己在后台运行（右下角托盘有个小羊驼图标）
  4. 回到向导点「🔄 重新检测」
     · 连上以后，点「⬇️ 下载模型」
     · 模型约 2GB，同样有进度条，可以取消
     · 中途取消**不会白下** —— Ollama 留着缓存，下次接着用
  5. 下完模型会**自动出现在「模型」下拉框里**，点一下选中
  6. 点「💾 保存并检测」，看到绿色"配置完成"就好了

  ⚠️ 常见卡点：
     · 安装包 1.5GB 是**正常的** —— 现在的 Ollama 把 GPU 运行库也打进去了
     · 模型名一个字符都不能错，打错了表现就是"发消息没反应"
       （所以用下拉框选，别手打）
     · Ollama 没启动 = 连不上。托盘图标没了就重新运行一下 Ollama
     · 一键下载失败的话：去 https://ollama.com/download 用浏览器手动下，
       下完双击安装，然后接着第 4 步
     · 想换别的模型：在第 4 步前先在「模型」框里改成别的名字
       （比如 qwen2.5:7b），再点「下载模型」

【路线B：云端 API（效果更好，按量付费）】
  1. 设置 → 模型 → 配置云端模型，先选「服务商」
     地址和模型名会自动填好，不用自己抄 URL
  2. 当前内置 8 类接入：
         OpenAI / Anthropic / Gemini / OpenRouter
         Azure OpenAI / LM Studio / llama.cpp server / vLLM
         以及「自定义 / OpenAI 兼容」
     国内常用：智谱 GLM、DeepSeek、通义千问、Kimi、硅基流动
     （仍可选「自定义」填它们的 OpenAI 兼容地址）
  3. Azure OpenAI 还需要填 deployment（模型框）和 API version
  4. 把 Key 粘进「Key」框；本地 LM Studio/llama.cpp/vLLM 通常不需要 Key
  5. 点「保存」

  ⚠️ Key 是密码，别发到群里。填错了会报 401。
  ⚠️ 想用别家的模型：服务商选「自定义（自己填）」，
     地址要填**完整的 chat/completions 地址**（只填域名会 404）。
  ⚠️ 模型能力和预估成本：Ctrl+K 搜「用量成本」；价格可写在
     data\config.json 的 model_prices 里覆盖。

四、界面怎么看
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    中间   聊天区（你的消息 + 它的回复）
    底部   输入框，打完按回车发送
    设置   所有功能入口都在这儿（见第六条）

  ★ 输入框：
      Enter 发送消息，Shift+Enter 换行

   Ctrl+K = 命令面板
    忘了功能在哪就按它，打字搜。所有能打开的东西都在里面，
    比记菜单位置快得多。

   右上角头像菜单固定 5 项：
    切换模式、检查更新、设置、登录/切换账号、帮助。
    其他功能不在头像里，统一去高级模式的「更多」菜单找。

五、工具模式（它一次能用的本领有多少）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
它会的本领有 60 多个。一口气全给它，容易选错。
所以有个「工具模式」开关，在 设置里改：

    日常    查天气、待办、笔记、翻译     （默认，最省心）
    干活    加文件读写、窗口操作
    编程    加跑代码、改文件
    维护    加记忆整理、数据清理
    全部    不限制（想干嘛干嘛，但容易选岔）

  建议：平时就放"日常"。要用电脑控制或写代码时再切。

六、设置里有什么（按简单 / 高级模式分）

  【简单模式】只有 3 个标签：
     开始    模型配置、本地/云端模型
     使用    界面、知识库、通知、更新、模式切换
     帮助    新手教程、安全中心、意见反馈、首次设置向导

  【高级模式】恢复完整标签：
     模型    模型管理、本地/云端切换
     界面    身份命名、字体、联网、AI 人格、模式切换
     工具    电脑控制、机器人、语音对话、日历待办、命令面板、模块星图
     扩展    插件市场（装/卸/热加载）、MCP 服务器、可选组件
     记录    历史记录、日志中心、搜索聊天、记忆可视化、数据统计
     系统    深度自检、首次设置向导、新手教程、检查更新、意见反馈
     开发者  命令面板、模块星图、日志等开发工具

七、记忆是怎么回事（它的核心）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  它把聊过的重要内容抽成一张张「记忆卡」，存在
      data\memory_cards.jsonl
  想看：设置 → 记录 → 记忆可视化
  在那儿能按时间看、按关键词搜、直接改、直接删。

  · 记忆整理：把重复/过期的卡片清理合并
    （设置 → 记录 → 记忆可视化 里有入口，或在聊天里说"整理一下记忆"）
  · 记忆加密导出：可以设个密码导出一份加密包，换电脑时导入
    ⚠️ 密码丢了就**没法恢复** —— 这是真加密，没有后门

八、让它动手（电脑控制 / 浏览器 / 文件）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【电脑控制】设置 → 工具 → 电脑控制
  能开软件、点按钮、打字、截屏、读写文件。
  ⚠️ 只允许白名单里的 28 条安全命令，别的会被拦下来问你要不要执行。

【浏览器】设置 → 工具 →（或直接说"帮我打开 xxx"）
  ⚠️ 第一次用会提示"浏览器内核没下载" —— 这是**正常的**，
     内核约 700MB，不随程序分发。按提示跑一次：
         py -3 -m playwright install chromium
     装完就能用了。

【语音】设置 → 工具 → 语音对话
  能听你说话（语音识别）、也能读出来（语音合成）。
  ⚠️ 这两个功能要额外装依赖，跑一次：
         scripts\install_optional.bat
     装完在设置里能看到状态。

九、插件（不装也能用，想扩展再装）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  设置 → 扩展 → 插件市场
  · 能在线装、也能卸载
  · 装之前会**验签**：不是官方签名的会拒绝安装
    （除非你自己在配置里显式开了允许无签名）
  · 插件清单带 api_version：当前公共 API 是 v1.0，版本不兼容会拒绝
  · 第三方插件只能用公开 API，不能依赖 core 私有实现；
    违规插件会在安装前被静态检查拦住
  · 模块是热加载的，装完不用重启

  ⚠️ 别手动去改 modules\installed\ 里的文件 ——
     那些是和签名清单一一对应的，改了会校验不过。
     要改就改源码目录，然后跑 tools\rebuild_modules_repo.py。

  ★ 插件标准（v1.0，已强制执行）
     每个插件必须在清单里声明三样东西：
       1. api_version：当前 1.0
       2. capabilities：网络/文件/子进程/界面控制/配置，5 段都要写
       3. sha256 + RSA 签名
     能力决定了插件能碰什么：
       · 网络    只能访问声明过的域名（本地服务可用 localhost/127.0.0.1）
       · 文件    只能读写 data\plugin_data\<插件名>\ 下面
       · 子进程  只能用清单里写死的 argv，不许用 cmd/powershell 包一层
       · 界面控制 属高风险，安装时会重点提示
     当前 42 个官方插件全部合规：42/42 有签名、42/42 声明能力、0 个未声明。
     完整规范见 docs\PLUGIN_STANDARD.md。

九点五、RAG、团队、成本和插件更新（2026-10-20 新增）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【RAG 知识库】Ctrl+K 搜「RAG管理」
  · 导入单个文件或整个目录
  · 角色框填 admin,editor,viewer，留空表示公开
  · 搜索结果显示来源、页码、offset 和引用位置
  · 可删除某个来源的索引
  · 底层使用增量索引：文件 sha256 没变不会重复入库

【团队 / 多用户】Ctrl+K 搜「团队管理」或「多用户」
  · 角色：owner / admin / editor / viewer / auditor
  · 登录账号会自动绑定团队角色
  · 管理员禁用账号后，该账号无法登录
  · 集中配置保存在 data\team\central_config.json，会覆盖用户本地配置
  · 审计可导出为 JSON（自动脱敏）

【模型用量与成本】Ctrl+K 搜「用量成本」或「模型用量」
  · 最近 7 天调用次数、Token、估算成本、P50/P95 延迟
  · 按模型分组
  · 未知模型显示 $0，不伪造费用

【插件更新与回滚】设置 → 扩展 → 插件市场
  · 点「检查更新」，只列出宿主版本和插件 API 兼容的版本
  · 可一键应用全部兼容更新
  · 更新前自动把旧文件放到 data\plugin_backups\
  · 单个插件卡片上可回滚
  · 插件卡片显示发布者、信任等级、版本、签名、API、能力和风险
  · 远程插件下载默认关闭（plugin_remote_install=false），
    开启后仍要求 HTTPS + 主机白名单 + RSA 签名

【电脑 Agent 失败修复】
  · 重试时会显示修复计划：刷新界面、滚动、切换定位源、等待、请求用户
  · 每一步都有动作、验证结果、重试次数和修复原因

十、出问题了怎么查（重要）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ★ 第一招：设置 → 系统 → 深度自检
    它会检查语法、模块、数据版本、配置、能力，把问题**直接列出来**。
    旧数据会在启动时先备份到 data\_migrations\，再按 v0→v1→v2
    自动迁移；迁移失败不会覆盖原文件，自检里会显示原因。

  ★ 第二招：设置 → 记录 → 日志中心
    三个标签页：系统日志 / 运行日志 / 操作记录。
    ⚠️ 报错的时候把「运行日志」最后几十行复制出来，基本就能定位。

  ★ 第三招：设置 → 记录 → 数据统计
    看用量和数据规模，判断是不是数据太多导致的慢。


  ★ 第四招：设置 → 系统 → 意见反馈
    可以直接给开发者留言。提交时会自动附带系统信息 + 错误行 +
    崩溃现场 + 日志路径（已脱敏，不含聊天内容）。
    崩溃 / 闪退也会自动上报，不用你手动发。

十一、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q1：发消息它不回？
      A：九成是模型没配好。设置 → 系统 → 首次设置向导，
         它会告诉你差什么。或者在对话里看有没有红色提示。

  Q2：提示"连不上本地 Ollama"？
      A：① Ollama 装了没 ② 它在不在运行（托盘图标）
         ③ 地址对不对（默认 http://localhost:11434）

  Q3：提示"Ollama 里没有 xxx 这个模型"？
      A：模型名和实际不符。去向导里点「重新检测」，
         从下拉框里选一个真实存在的。

  Q4：说话没反应 / 语音功能点不动？
      A：可选依赖没装。跑 scripts\install_optional.bat，
         然后在设置里看「可选功能状态」。

  Q5：浏览器功能报"内核没下载"？
      A：正常的，见第八条。跑一次 playwright install chromium。

  Q6：想恢复默认配置？
      A：数据都是文件，直接改：
         data\config.json      程序配置
         data\rules\rules.json 规则开关
         改坏了程序会自动补齐缺失项（不会崩），但建议先备份整个 data\。

  Q7：换电脑怎么搬？
      A：整个文件夹拷过去就行。但有个例外 ——
         optional_libs\（约 1GB）和 data\browsers\（约 700MB）
         **不用拷**，对方机器上按需装即可，能省 1.7GB。
         剩下必需的部分只有 60~240MB。

  Q8：它记错东西了怎么办？
      A：设置 → 记录 → 记忆可视化，找到那张卡片直接改或删。

十五、简单模式 / 高级模式怎么用


 普通使用建议留在简单模式：
  首屏只保留聊天、任务、资料、设置和输入区，不容易迷路。

 想用高级功能时，点右上角头像  切换模式，进入高级模式：
  模块按钮、模型选择、代码编辑器、实时对话、安全中心、插件市场、
  MCP、记忆、日志等都会恢复。

 头像菜单固定只有 5 项：
  切换模式、检查更新、设置、登录/切换账号、帮助。

 高级模式右上角会出现更多按钮：
  其他功能都在里面，按任务 / 资料 / 工具 / 安全 / 插件-MCP / 开发分组，
  重复的入口不会出现。

 左侧模块区域显示模块（N），N 是当前可用模块按钮数量；
  内容多时左栏可以上下滚动，不会再把按钮裁掉。

 输入框左边可以切换 [聊天] / [任务]：
  复杂目标建议切到任务，它会显示计划、步骤、结果和失败下一步。

十七、兼容性、升级与旧数据（v25.2.23 补）

  1. 系统
     Windows 10 / 11：主支持环境，推荐。
     Windows 7 / 8：不建议使用。
     Windows Server：部分功能可运行，但不是主要目标。
     macOS / Linux：聊天、部分文件功能可能可用；电脑控制、窗口操作、
     截图、剪贴板、自动安装等桌面 Agent 核心能力基本不可用。

  2. Python
     Python 3.10 / 3.11 / 3.12：支持。
     Python 3.9 及以下：不支持（代码使用了 3.10+ 语法）。
     Python 3.13：尚未验证，PyQt5 等依赖可能不兼容。

  3. 旧配置和旧数据
     · data\config.json 会自动补默认字段，类型错误回退默认值。
     · 启动时检查 data\_schema.json 里的数据版本。
     · 旧数据按 v0→v1→v2 逐级迁移；迁移前先备份。
     · 备份位置：data\_migrations\backup_日期时间\
     · 迁移失败不会静默覆盖原文件；到 设置→系统→深度自检
       和 data\logs\trunk.log 查看原因。
     · 加密数据：新数据 AES-GCM；旧 XOR 只读兼容；
       记忆导出兼容 X6MEM2 / 旧 AES / XOR。

  4. 插件
     · 当前插件公共 API 版本：v1.0。
     · 只安装带签名、清单 api_version 兼容的插件。
     · 第三方插件只能依赖公开 API，禁止 import core 私有实现。
     · 官方随包模块和第三方插件都会经过静态边界检查；
       手动改 modules\installed\ 后必须重新 rebuild + sign。

  5. 出了兼容性问题先做什么
     ① 设置→系统→深度自检；
     ② 设置→记录→日志中心，看最近 error；
     ③ 不要先删 data\；先备份整个 data\ 再排查；
     ④ 开发/发布前跑 Windows + Python 3.10/3.11/3.12 兼容矩阵
       和 tools\check_plugin_api.py。

## 启动性能（2026-10-20）

- 启动打点：`core/startup.py`，日志里搜 `[启动耗时]`。
- 秒开策略：`JarvisWindow(boot_signal=False)` 先出骨架，`gui/boot_controller.py`
  在事件循环后创建 Trunk 并补挂界面。
- 看门狗在 `run.py` 里早于 Qt 拉起，独立进程，不受界面耗时影响。
- 模块星图导出与 LLM 预热/看门狗都改成启动后后台执行。
- 需要旧行为（全部就绪才显示）时设 `X6_BLOCKING_BOOT=1`。
- 实测：界面可见约 0.16~0.20 秒，全功能就绪约 1.0~1.2 秒。

十二、界面全白 / 弹窗太多怎么处理（2026-10-21 修复）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【白屏有两种，先看底部状态栏】

  类型 A：底部状态栏文字正常，中间一片空白、没有任何按钮
      → 这是"界面被清空"，不是字体问题。
        2026-10-21 已修复（启动收尾时误把主界面拆掉）。
        如果你还看到这种画面，说明你运行的是旧版本 exe / 旧源码，
        请更新到最新版本后重新启动。

  类型 B：连按钮上的字、侧栏文字都是空白色块
      → 这是 Qt 找不到字体。
        新版启动时会自动从 C:\Windows\Fonts 注册
        微软雅黑 / 黑体 / 宋体 / Segoe UI，通常不需要你做什么。
        仍然全白时：
          1. 确认 C:\Windows\Fonts\msyh.ttc 存在（微软雅黑）
          2. 设置 → 系统 → 深度自检，看"字体"那一行
          3. 精简版 Windows 需要补装中文字体

  自查小技巧：
      打开 data\logs\trunk.log，搜"[启动耗时]"那一行。
      如果里面有"字体就绪(数字)"且数字大于 0，说明字体没问题，
      那就是类型 A。

【一打开就弹好几个窗】
  已改为串行：协议 → 登录 → 首次配置向导，一次只出现一个。
  如果你连续看到多个框，说明版本较旧，请更新。

【代码编辑器行号刷屏报错】
  已修复（旧版会刷 "'QWidget' object has no attribute 'contentOffset'"）。

【启动后界面是白的，但过一会儿自己好了？】
  正常：新版是"先出窗口骨架、再装界面"，
  中间会短暂看到"正在启动…"占位页，一般 1 秒内变成完整界面。
  如果一直停在"正在启动…"，看 data\logs\trunk.log 最后几行。

新增：🧰 工作台（2026-10-22）
================================================================================
以前「代码编辑器」「Agent 旅程」「AI 代码 Agent」是三个独立窗口，
改完 AI 生成的代码想手动调一下，得关掉一个再开另一个。

现在合并成**一个工作台窗口**，左边文件树，右上编辑器，右下 AI 面板：

    +--------------+----------------------------------+
    | 文件树        | 编辑器（多个文件用标签并排）        |
    |              +----------------------------------+
    |              | 🤖 AI 面板（描述目标就开干）        |
    +--------------+----------------------------------+
    | 运行输出                                          |
    +--------------------------------------------------+

怎么用：
  1. 点顶部「</> 代码编辑器」按钮 → 打开工作台
  2. 在文件树里双击文件 → 编辑器打开
  3. 在下方 AI 面板写「给 main 加参数解析」→ 点「▶ 开始」
  4. AI 改完会弹 diff 让你审批；左边代码区同步看到结果
  5. 想手动微调 → 直接在上方改；想继续让 AI 改 → 在下方再说一句

快捷键：
  Ctrl+J   收起 / 展开 AI 面板
  F11      全屏 / 退出全屏

AI 面板还能「⛶ 弹出」成独立小窗，拖到第二块屏幕上边看边改。

================================================================================
位置：🧷 MCP → 🔐 信任管理

MCP 服务器每次启动都要确认一次。点过「永久允许」后就不再问了。
这一页能看到每个服务器的状态和哈希，也能：
  · 「全部永久信任（不再弹窗）」一键授权全部
  · 「撤销全部信任」让它们重新询问

注意：如果命令内容被改了（比如换了参数），哈希会变，会重新问你一次
     —— 这是防止命令被偷偷替换的保护，不是故障。

如果程序在虚拟机、模型在物理机：
  1. 物理机：设 OLLAMA_HOST=0.0.0.0:11434，重启 Ollama

  5. 看到"已检测到 N 个模型"就成功了
