一、这是什么
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一个住在你电脑里的 AI 助手。和普通聊天 AI 的区别：

  · 记忆是自己的
    聊过的重要内容会存成一张张「记忆卡」，存在本地；
    重启不丢，而且能看、能搜、能改、能删。

  · 脑子可以是本地的
    装一个 Ollama 就能完全离线使用，不联网也能聊。
    也可以接云端模型，效果更好，但要按量付费。

  · 能动手
    不只是聊天：能开浏览器、操作窗口、跑代码、读写文件、
    看图片、听你说话。

  · 数据基本都在本地
    聊天记录、记忆、配置都在 data\ 目录下，不会主动上传。
    唯一例外：程序崩溃时会自动发一份「脱敏摘要」
    （系统信息 + 错误行 + 调用栈 + 日志路径，不含聊天内容）。
    不想要可以改 data\config.json 里的 auto_report_crash。

二、安装与第一次启动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【怎么打开】
  方法 1：双击「启动PyQt.bat」
  方法 2：在程序文件夹里打开命令行，输入
            py -3 run.py

【第一次打开的顺序】
  程序会按顺序弹三个窗口，一次只出现一个：
      用户协议 → 登录 / 激活 → 首次设置向导
  如果你看到好几个窗口叠在一起，说明是旧版本，更新后再用。

  第一步：同意用户协议
      读完勾选同意，点继续。

  第二步：登录或激活
      · 已有账号：输入账号名，点「登录」
      · 第一次使用：点「激活」，输入账号名 + 激活码
      · 一个激活码只能激活一个账号
      · 激活成功后会自动绑定团队角色（默认 viewer）

  第三步：首次设置向导
      花一分钟按提示配模型（详见第三节）。
      不想现在配也可以，先关掉，之后在设置里再配。

【登录状态会被记住】
  · 登录成功一次，下次打开直接进主界面，不用再输账号
  · 只记住账号名，不保存密码或激活码
  · 每次启动仍会重新校验激活码、有效期、账号状态
  · 激活到期或被管理员禁用，会自动回到登录界面

【想重新登录 / 换账号】
  高级模式：左侧栏底部「🔑 登录」按钮。
  任何模式：Ctrl+K 搜「登录」。
  想重新配模型：设置 → 系统 → 首次设置向导（高级模式）。

三、配模型（唯一必须做的一步）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
模型就是它的「大脑」。两条路，选一条就行，向导里都有。

【路线 A：本地 Ollama（免费，推荐，断网也能用）】
  作用：模型和聊天都在你自己电脑上跑，不花钱、不联网。

  操作步骤：
    1. 在首次向导里点「⬇️ 一键下载 Ollama 安装包」
       · 约 1.5GB，程序会自动挑国内加速源
       · 有进度条，显示速度和剩余时间；下不动可以点「取消下载」
    2. 下完按钮变成「📦 立即安装」，点它，按安装向导点完
       · 装到哪个盘可以自己选
    3. 装完 Ollama 会在后台运行（右下角托盘能看到小羊驼图标）
    4. 回到向导点「🔄 重新检测」
       · 连上以后点「⬇️ 下载模型」
       · 模型约 2GB，同样有进度条，也可以取消
       · 中途取消不会白下：Ollama 会留缓存，下次接着用
    5. 下载完，模型会自动出现在「模型」下拉框里，点一下选中
    6. 点「💾 保存并检测」，看到绿色「配置完成」就好了

  常见卡点：
    · 安装包 1.5GB 是正常的，现在的 Ollama 把 GPU 运行库也打进去了
    · 模型名一个字符都不能错；用下拉框选，别手打
    · Ollama 没启动就连不上：托盘图标没了，就重新运行一次 Ollama
    · 一键下载失败：去 https://ollama.com/download 用浏览器手动下，
      双击安装，然后回到第 4 步
    · 想换别的模型：在第 4 步前把「模型」框改成别的名字
      （比如 qwen2.5:7b），再点「下载模型」

  在哪里重新配：
    简单模式：设置 → 开始
    高级模式：设置 → 模型

【路线 B：云端 API（效果更好，按量付费）】
  作用：用服务商的在线大模型，回复质量更高，但会产生费用。

  操作步骤：
    1. 打开「设置 → 模型 → 配置云端模型」
    2. 先选「服务商」，地址和模型名会自动填好，不用自己抄 URL
    3. 把 Key 粘进「Key」框
    4. 点 Key 框下面的蓝字「🔌 测试云端连通」
       · 它会真的发一个 8 token 的小请求，几乎不花钱
       · 成功显示「✅ 云端连通」，再点「保存」
    5. 左下角两个小圆点是状态灯：本地模型 / 云端模型

  内置的 8 类接入：
      OpenAI / Anthropic / Gemini / OpenRouter
      Azure OpenAI / LM Studio / llama.cpp server / vLLM
      以及「自定义 / OpenAI 兼容」
    国内常用：智谱 GLM、DeepSeek、通义千问、Kimi、硅基流动
    （选「自定义 / OpenAI 兼容」，填它们的兼容地址）

  注意事项：
    · Azure OpenAI 还要填 deployment（模型框）和 API version
    · Key 是密码，不要发到群里或截图里
    · 测试失败的常见原因：
        401  Key 不对或已过期
        404  地址不对（自定义时要填完整的 chat/completions 地址）
        429  额度用完或被限流
        连不上  网络或代理问题
    · 401 不一定是 Key 失效：如果配置是从别的电脑拷来的，
      加密 Key 可能解不开。去服务商后台重新复制一份明文 Key 填回来。
    · 本地 LM Studio / llama.cpp / vLLM 通常不需要 Key

【虚拟机连物理机上的 Ollama】
  如果程序在虚拟机、模型在物理机：
    1. 物理机：设环境变量 OLLAMA_HOST=0.0.0.0:11434，重启 Ollama
    2. 物理机：ipconfig 查到局域网 IP，例如 192.168.1.2
    3. 程序：设置 → 模型 → 本地模型地址填 http://192.168.1.2:11434
    4. 程序：右键点「检测本地模型」→「信任当前主机」
    5. 看到「已检测到 N 个模型」就成功了

【想看花了多少钱】
  Ctrl+K 搜「用量成本」或「模型用量」，可以看到：
    · 最近 7 天调用次数、Token 数、估算成本
    · P50 / P95 延迟，按模型分组
    · 未知模型显示 $0，不会伪造费用
  想改价格：data\config.json 里的 model_prices。

四、界面怎么看
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【主界面三块】
  左边   新建对话、历史对话、模块按钮、设置、清空聊天
          底部还有「🧭 任务中心」「⌘ 命令面板」「🔑 登录」（高级模式）
  中间   聊天记录区（标题、列表、代码块会自动排版，代码块可一键复制）
  底部   输入框 + 一排按钮（＋ / 聊天·任务 / 🎙 语音 / 🎧 实时对话 /
          🤖 模型 / 🧰 工作台 / 发送）

【右上角头像菜单（4 项）】
  切换模式、检查更新、设置、帮助。
  登录 / 切换账号在左侧栏底部的「🔑 登录」按钮。
  其他功能不在头像里，去高级模式的「更多」菜单找。

【简单模式 / 高级模式】
  简单模式：首屏只保留聊天、任务、资料、设置和输入区，不容易迷路。
    设置只有 3 个标签：开始 / 使用 / 帮助。
  高级模式：恢复全部功能。
    设置有 9 个标签：模型 / 界面 / 工具 / 扩展 / 记录 / 数据 /
                    依赖 / 系统 / 开发者。
    右上角会出现「更多」按钮，按任务 / 资料 / 工具 / 安全 /
    插件-MCP / 开发 / 帮助分组，重复入口不会出现。

  切换方法：头像 → 切换模式。
  左侧模块区显示「模块 (N)」，N 是当前可用模块按钮数；
  内容多时左栏可以上下滚动。

【输入框左边可以切 [聊天] / [任务]】
  普通聊天选「聊天」。
  复杂目标（比如「帮我整理这 20 个文件并生成报告」）建议切「任务」，
  它会显示计划、每一步状态、结果和失败后的下一步。

【命令面板 Ctrl+K（最该记住的功能）】
  作用：忘了功能在哪时，打字搜，所有入口都在里面。
  怎么用：
    1. 按 Ctrl+K
    2. 输入几个字，例如「记忆」「日志」「插件」「教程」「反馈」
    3. 回车执行，或点条目
    4. Esc 关闭搜索框
  装了新插件后，新能力也会自动出现在这里。

【界面全白 / 启动卡住】
  见第十七节「出问题怎么查」。

五、日常聊天
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【发消息】
  · Enter 发送，Shift+Enter 换行
  · 回复边生成边排版；代码块右上角可一键复制
  · 回复过程中按 Esc 可以停止：
      已经吐出来的内容会保留、排版好、存进这段对话
      后台也会立刻停下，可以马上发下一条
  · 回复没结束时再点发送会先提示，不会两条回复搅在一起

【发文件】
  作用：把文档内容直接交给它分析，不用复制粘贴。
  操作：
    1. 把 PDF / Word / Excel / PPT / Markdown / HTML 拖进输入框
    2. 程序会自动解析成文字，放进输入框
    3. 再补一句要求（例如「总结这份合同的要点」），按 Enter 发送
  · 不支持的文件类型会明确提示，不会「什么都没发生」

【输入框左边的「＋」菜单】
  点输入框左边的「+」，可以看到：
    · 上传文件：选文件发给它
    · 📷 发图片：选一张图片让它看
    · 送工作台：把上一条回复里的代码发到工作台
    · 区域截图：框选屏幕区域，直接发给它
    · 导出聊天记录
    · 自动朗读开关：让它把回复读出来（点了会提示"已开启/已关闭"）
        没声音怎么办：先看系统音量与播放设备；在线语音（edge-tts）连不上时
        程序会自动改用**系统朗读**（音色差点，但一定有声音）。
        想要纯粹静音：把 data\rules\rules.json 里的 语音.本地兜底 改成 off。
    · 🔊 朗读音色：换声音（晓晓/晓伊/云希/云健/云夏/云扬/晓北/晓妮/曉曼/曉臻）
        勾一下就生效，不用重启；**朗读和「🎧 实时对话」共用同一个音色**。
        选了之后菜单会显示「当前：某某」。
        子菜单里的「▶ 试听当前音色」会立刻念一句，方便比较哪个更像真人。
        朗读前会自动"洗稿"：去掉 **加粗**、代码块、emoji 和链接，
        换行变成停顿 —— 所以不会再听见"星号""井号"或整段代码。
        说明：在线合成最多等 3 秒拿到**第一块**音频（规则 语音.首包上限ms 默认 3000），
        首包到手后整句会正常写完 —— 长句不会被截断。
        如果在线连不上，会改用**系统朗读**：系统里通常只有一个中文音色，
        只有音调差别（男声会自动降调），听上去不会像网上的自然音色。
    · 截图识字（开发中）

【发截图 / 图片】
  作用：让它看图回答（需要模型支持多模态）。
  操作：
    · Ctrl+V 直接粘贴截图，自动存到 data\paste_images\ 并走识图流程
    · 或点输入框左边「＋」→「📷 发图片」，选一张图片发过去
  说明：
    · 模型支持多模态（如 GPT-4o、Qwen-VL）时，它真的能看到图片内容
    · 模型不支持时会告诉你「我这个模型看不了图片」

【语音输入】
  作用：不想打字时直接说话。
  操作：
    · 点一下「🎙 语音」：固定录 5 秒，适合说一句短话
    · 按住不放：说完松开，立刻开始识别（最长 20 秒）
  前提：可选依赖已安装（见第十七节）。

【指代消解（说「它 / 这个 / 继续」也能懂）】
  作用：自动把含糊的话补成上一轮的话题。
  例子：上一轮在聊「贪吃蛇」，这轮说「把它改成蓝色」，
        程序会自动补成「把贪吃蛇改成蓝色」。
  聊天区会显示一行「🔎 已把…补全为…」，可以核对。

【聊天区右键菜单】
  复制选中 / 复制上一条回复 / 重发上一条 / 编辑上一条 /
  继续这个话题 / 聊天话题时间线。

【聊天话题时间线】
  作用：按话题列出这一轮会话，快速跳回原来的消息。
  操作：
    1. Ctrl+K 搜「聊天话题时间线」
    2. 双击某条话题，跳回对应消息
    3. 顶部输入框可以过滤话题

【回复过程看得见】
  它一边干活一边在回复上方显示步骤条（查记忆 → 组织提示 → 生成 → 收尾）：
    · 正在做的那一步高亮，做完的打勾
    · 每一步带预计剩余时间（按前面几步的实际耗时估算）
    · 某一步卡住可以只停那一步（比如只停「生成」），不用整段对话退出
    · 点「取消这一步」后，步骤条上会留下「已取消这一步」的提示，不会一闪而过
  不想要步骤条：把 data\rules\rules.json 里的 聊天.过程可见 改成 shadow
  （只记日志不显示）或 off（彻底关掉）。

【失败会分型，不再一句「网络问题」】
  空回复 / 被截断 / 重复说同一句 / 接口报错，程序分开判断：
    · 能自动重试的先重试一次
    · 重试也不行才提示，并说清是哪一类问题、下一步怎么办

【说话更像真人（少 AI 腔、多具体细节）】
  作用：回复用词更口语，别动不动"作为一个AI…""希望对你有所帮助"，
        也别用"这取决于很多因素"糊弄，尽量给具体的东西。
  分两层做的：
    1. 提示词层：人格卡和人格宪法里写死"短句口语，能带细节就带细节
       （版本号 / 文件路径 / 第几步 / 多少 MB / 身边的例子）"，
       示例也换成了带数字的（电脑卡先看内存占比 80%、学英语每天 20 分钟）。
    2. 出站清理层：回复发出来之前再扫一遍，把这几类直接删掉——
         · "作为一个AI，" / "作为一个人工智能助手，"（开头自我介绍）
         · "希望对你有所帮助" / "很高兴为您服务" / "还有其他问题吗"（客服结尾）
         · "首先，" / "其次，" / "总之，" / "综上所述，" / "以下是"（作文模板）
       ``` 代码块一个字符都不动；整条回复都是客套话时会保留原话，
       不会把回复清成空白。它是无条件跑的，跟"聊天.校验器"开关无关。
  想调：
    · 设置 → 使用 → AI 人格：写自己的说法，会优先于默认人格卡
    · data\persona_tiers.json：整套换人格卡（风格、场景、禁语表都在里面）
    · 录音朗读也受益：朗读前会把符号、代码、emoji 洗掉（见「＋」菜单）

【群聊 / 辩论】
  作用：让几个角色一起讨论同一个问题，适合对比方案、头脑风暴。
  说明：
    · 群聊里的「小七 / 小八 / 小九」是聊天人设
    · 人设只负责说话风格，不会自动跑「三个子智能体」的工具链
      （工具链见第九节）

  记忆卡存在 data\memory_cards.jsonl（一行一张）。

【查看 / 修改 / 删除】
  操作：

    3. 直接改内容，或点删除

【整理记忆】
  作用：把重复、过期的卡片清理合并，少占地方、少干扰。
  操作：
    · 在记忆可视化窗口里有整理入口
    · 或直接在聊天里说「整理一下记忆」
  注意：整理前建议先备份 data\ 目录。

【记忆加密导出（换电脑时用）】

  ⚠️ 密码丢了没法恢复：这是真加密，没有后门。

【它记错了怎么办】

  如果它总是记错，也可以把整段相关记忆删掉，再重新告诉它正确信息。

七、让它动手：电脑控制 / 浏览器 / 网页操作
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【电脑控制】
  作用：开软件、点按钮、打字、截屏、读写文件、操作窗口。
  操作：
    1. 设置 → 工具 → 电脑控制（Ctrl+K 搜「电脑控制」也能开）
    2. 在里面选择要做的动作，或直接在聊天里说
       「帮我打开记事本」「帮我找一下这个文件」
    3. 危险动作会弹窗确认，确认后才执行
  安全规则：
    · 只允许白名单里的 28 条安全命令
    · 其他命令会被拦下来，问你要不要执行
    · 不确定就点「取消」，不会有副作用

【浏览器】
  作用：让它打开网页、搜索、读取页面内容。
  操作：
    · 直接说「帮我打开 xxx」「搜一下 xxx」
    · 需要固定窗口操作时，用 设置 → 工具 → 电脑控制
  第一次使用会提示「浏览器内核没下载」：
    · 这是正常的，内核约 700MB，不随程序分发
    · 按提示在命令行跑一次：
          py -3 -m playwright install chromium
    · 装完就能用了

【网页自动操作（web_agent）】
  作用：它自己开浏览器、截图、分析页面、点按钮、输入文字。
  例子：
    「帮我打开百度，搜一下今天天气」
  操作流程（它会自动做）：
    开浏览器 → 截图 → 分析页面 → 点搜索框 → 输入文字 → 按回车
  限制：
    · 最多自动操作 5 步，不会无限循环
    · 每一步做完会验证是否成功
    · 需要先装好浏览器内核

【电脑 Agent 失败重试】
  作用：操作没成功时，它会给出修复计划，而不是直接放弃。
  你会看到每一步的：
    动作、验证结果、重试次数、修复原因
  常见修复：刷新界面、滚动、切换定位源、等待、请求用户手动处理。

八、工作台：写代码、改代码
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【作用】
  以前「代码编辑器」「Agent 旅程」「AI 代码 Agent」是三个独立窗口，
  现在合并成一个工作台：文件树、编辑器、AI 助手、终端都在一处。
  用一句自然语言就能让它写代码、改代码，改完还能自己跑测试。

【怎么打开】
  · 主界面底部「🧰 工作台」按钮
  · 或「更多」菜单 → 工具 → 🧰 工作台
  · 或 Ctrl+K 搜「工作台」

【界面布局（VS Code 风格）】
  左边活动栏：6 个图标（灰；选中变蓝）
    资源管理器 / 搜索 / 源代码管理 / 运行 / 扩展 / AI（四角星）
  侧栏（三选一）：资源管理器 / 搜索 / 源代码管理
  中间：标签栏 → 面包屑 → 编辑区（右侧 minimap）
  底部：输出 / 问题 / 终端 / 差异 / 测试
  最右：AI 助手（可以弹出成独立小窗）
  最底状态栏：分支 · 行列 · 语法错误数 · 语言 · 路径/编码

【用自然语言写代码：完整步骤】
  前提：设置 → 模型里已经配好可用模型（没有模型不能写代码）。

    1. 点底部「🧰 工作台」
    2. 左侧文件树双击要改的文件；新文件可以右键新建
    3. 在右侧 AI 面板输入要求，例如：
         写一个贪吃蛇小游戏 snake.py，带得分、暂停和重新开始
         给 main 加命令行参数解析，并补一条 pytest
    4. 按 Ctrl+Enter，或点「▶ 开始」
    5. 时间线会依次显示：
         选执行域 → 收集上下文 → 生成计划/改动 →
         内联 diff → 应用 → 跑测试
       · 弹计划确认：看没问题点「是」
       · 弹 diff 审批：确认没问题点「✓ 应用全部修改」
    6. 应用成功后，编辑器自动打开真实文件，完整代码就在里面
       · 可以直接手改，Ctrl+S 保存
       · 想让它继续改，再写一句，再按 Ctrl+Enter
    7. 不满意：
       · diff 页点「↩ 撤销本次修改」整体退回
       · 或者先看 diff，确认后再应用

【代码写到哪个文件夹（可以选，而且会记住）】
  AI 写的文件默认落在"程序自己的目录"里，会和程序源码混在一起，
  所以第一次打开工作台，状态栏会提醒你换个目录。
  怎么换：
    1. 点工作台顶栏「📂 打开文件夹」
       （也可以在 Ctrl+Shift+P 命令中心搜「打开文件夹」）
    2. 弹窗里左侧第一项就是「🖥 桌面」，接着是
       「🏠 用户文件夹」「📄 文档」「📥 下载」和各个磁盘
       · 想去别的地方：在上方「位置：」里粘贴完整路径，回车
       · 想当场建目录：点「＋ 新建文件夹」
    3. 选中目标文件夹 → 点「选择」
  说明：
    · 选过一次就记住（存在 config.json 的 workbench_root），
      下次打开工作台直接用它
    · 切换只改"写到哪里、文件树看哪里"，
      已经打开的编辑标签不会丢
    · 上一个任务还在跑时不会切，会提示等它结束

【三种执行方式】
  · 默认：代码任务，直接改文件
  · 想普通聊天：目标前加 /chat
  · 想操作电脑：目标前加 /pc（/computer 也行）
  时间线里会显示当前是「代码 / 对话 / 电脑」哪一种执行域。

【改之前先看 diff】
  AI 给出改动后会打开内联 diff（左边文件、右边增删行）：
    · 点某一行：编辑器直接跳到对应文件那一行
    · 点「✓ 应用全部修改」：真正写盘（写前自动备份）
    · 点「↩ 撤销本次修改」：把这一轮改动整体退回去

【一次改多个文件不会改一半】
  应用前会先在内存里把整批改动「预演」一遍。
  只要有一个文件对不上（比如你刚手动改过），整批都不落盘。
  不会出现「改了三个，前两个成功、第三个失败」的半截状态。

【它什么时候会停（时间线会写原因）】
  · 测试和检查全绿：说明改好了，结束
  · 连续两轮报的错一模一样：判定原地打转，停下来等你接手
  · 轮次用完：到上限（轮次上限 1~15，默认 12）
  · 预演失败：一批改动里只要有一处不对，整批都不写盘

【改代码更稳：只动该动的那几行】
  · 模型给的改动按「行段」应用，不再整文件覆盖，无关代码不会被顺手改掉
  · 原文被你手动改过时，会按上下文锚点模糊定位，仍然能落到正确位置
  · 应用前对比磁盘上的最新内容；不一致会问你：
      保留我的 / 用 AI 的 / 手动合并
  · 每个行段单独留快照，可以只撤销其中一段，不用整轮退回
  · 只允许改任务相关的文件；想动别的文件会再问一次
  （规则 code.改动范围，默认 ask；不想要这层确认可改成 strict 或 off）

【检查与修 bug（重点）】
  · 问题页现在同时能报三类问题：
      语言服务诊断（类型错误等）、ruff 静态检查、语法错误；
      同一处只显示一条，不会同一行报三遍
  · 打字停下约 1.2 秒自动检查一次，没保存的内容也算；
    所有问题行都画红色波浪线（以前只画第一条）
  · 问题页里 红色=错误，橙色=警告；双击跳到那一行
  · 问题页右键 →「🛠 让 AI 修这一行」：只改这一行，
    改完先给你看 diff，确认后才写入编辑器
  · 编辑器里也能右键「🛠 让 AI 修这一行（第 N 行）」
  · 运行失败时，报错里的「文件:行」会直接进问题页，点一下就跳到出错那行
  · 想在规则里关掉：data\rules\rules.json 里
      编辑.LSP诊断优先 / 编辑.实时检查 / 编辑.一键修复 改成 false

【跨文件找代码更准】
  · 让它改一个函数时，会顺手带出：同文件相关符号、引用它的地方、
    对应的测试文件，以及引用了这个模块的其他文件（每段都标了来源）
  · 项目「符号地图」按引用热度排序，重要的放前面，而不是按字母排
  · 可选：用向量库按语义召回代码片段（默认关，会和记忆检索抢额度；
    想开就把 data\rules\rules.json 里的 代码.语义检索 改成 true）

【语言服务与格式化】
  · 装了语言服务（如 pyright / pylsp）就能跳定义、找引用、重命名、看类型诊断；
    没装会自动退回内置 jedi，功能不中断，并提示装了什么会更准
  · 保存时自动格式化默认是关的（不会悄悄重排你的文件）；
    想开：data\rules\rules.json 里把 编辑.保存格式化 改成 on，
    或直接右键「格式化当前文件」
  · AI 应用改动前会先格式化目标文件；格式化后语法不通过就不写盘

【轮次上限怎么改】
  AI 面板上方有「轮次上限」数字框，范围 1~15。
  复杂改动可以调大，简单改动调小更快停。

【任务队列 / 断点续跑】
  AI 面板下面有任务列表。
  程序关了、崩了再打开，没跑完的任务会标成「已中断」；
  双击那条任务，从上次停下的那一轮继续，不用从头再来。

【直接推到 GitHub】
  编辑器标签上右键 →「推送到 GitHub 并创建 PR」。
  流程：建分支 → 提 PR → 等 CI → 绿灯后合并。
  安全说明：
    · 推送前会要你确认权限
    · 不会直接往 main 上推
    · Token 不会写进日志，也不要用截图把 Token 发出去

【找代码更准】
  让它「找一下 xxx 函数」时，用的是真正的符号索引：
    · Python 按语法树解析，能分清函数 / 类 / 方法 / 嵌套函数
    · JavaScript / TypeScript 优先用 tree-sitter
    · 没装 tree-sitter 会退回文本搜索，结果里会标「引擎：regex」

【左侧三个视图】
  资源管理器：
    · Git 改动用颜色标（M 琥珀 / A 绿 / D 红 / ? 灰）
    · 右键可新建文件/文件夹、重命名、删除、在资源管理器中显示
    · 顶部「筛选文件…」：输入几个字只显示匹配的文件
  搜索：
    · 优先用 rg，没装就用内置文本搜索
    · 双击结果跳到对应行
  源代码管理：
    · 当前分支 + 改动列表，双击打开文件

【底部五个页】
  输出：运行结果。结束时先给结论：
        「📌 运行完成 / 异常类型 + 位置」和「💡 下一步」
        例如缺包会直接指向安装入口
  问题：语法错误 / ruff 检查 / 语言服务诊断（同一处只留一条，红色=错误、橙色=警告）；
        双击跳到对应行，右键「🛠 让 AI 修这一行」；
        多个标签页的问题会合并计数，修好会自动减少
  终端：支持 cd / pwd / cls，其余命令一次性执行
  差异：git diff 按 +/- 着色
  测试：
    · 「受影响测试」：按当前打开的文件反查测试文件
    · 「运行全部」：跑 pytest -q
    · 「只重跑失败」：只重跑上一轮失败的用例
    · 失败行双击跳到代码行；下方实时显示 pytest 输出

【标签页右键】
  · 发送到 AI（含选区）：
      有选区只发选区（带「文件:行」），没有就发整文件
      也可以直接按 Ctrl+Shift+A
  · 插入函数调用模板：
      光标在函数体内时，生成 foo(a=a, b=b) 这样的调用

  F11            全屏

  · AI 面板「⛶ 弹出」成独立小窗，可以拖到第二块屏幕
  · 历史保留最近 20 条
  · 运行前会在输出页先给结论和下一步提示

【分析专家】

  怎么用：Ctrl+K 搜「分析一下」「对比一下」。
  特点：
    · 对比时会自己算两边的差值和变化率
    · 没配模型也能用，只是会给一份结构化清单

【编程小匠】

十一、插件与 MCP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【插件市场：不装也能用，想扩展再装】
  作用：给程序加新能力（新工具、新面板、新自动化）。
  操作：
    1. 设置 → 扩展 → 插件市场（Ctrl+K 搜「插件」也能开）
    2. 选插件 → 安装
    3. 装完是热加载，不用重启
    4. 不想要就卸载

【装插件时的安全校验】
  · 装之前会验签：不是官方签名的会拒绝安装
    （除非你自己在配置里显式开了允许无签名）
  · 插件清单带 api_version：当前公共 API 是 v1.0，
    版本不兼容会拒绝
  · 第三方插件只能用公开 API，不能依赖 core 私有实现；
    违规插件会在安装前被静态检查拦住

【插件标准（v1.0，已强制执行）】
  每个插件必须在清单里声明：
    1. api_version：当前 1.0
    2. capabilities：网络 / 文件 / 子进程 / 界面控制 / 配置，5 段都要写
    3. sha256 + RSA 签名
  能力决定插件能碰什么：
    · 网络     只能访问声明过的域名（本地服务可用 localhost / 127.0.0.1）
    · 文件     只能读写 data\plugin_data\<插件名>\ 下面
    · 子进程   只能用清单里写死的 argv，不许用 cmd / powershell 包一层
    · 界面控制 属高风险，安装时会重点提示
  当前 48 个官方插件全部合规：
    48/48 有签名、48/48 声明能力、0 个未声明。
  完整规范见 docs\PLUGIN_STANDARD.md。

【插件更新与回滚】
  操作：插件市场 →「检查更新」。
  · 只列出和宿主版本、插件 API 兼容的版本
  · 可一键应用全部兼容更新
  · 更新前自动把旧文件放到 data\plugin_backups\
  · 单个插件卡片上可回滚
  · 卡片会显示发布者、信任等级、版本、签名、API、能力和风险
  · 远程插件下载默认关闭（plugin_remote_install=false）；
    开启后仍要求 HTTPS + 主机白名单 + RSA 签名

【不要手动改已安装模块】
  ⚠️ 别手动去改 modules\installed\ 里的文件：
     它们和签名清单一一对应，改了会校验不过。
     要改就改源码目录，然后跑 tools\rebuild_modules_repo.py。

【MCP 服务器】
  作用：把外部工具/服务接进来（比如数据库、文件系统、第三方 API）。
  操作：
    1. 设置 → 扩展 → MCP（Ctrl+K 搜「MCP市场」）
    2. 里面预置了 15 个常用 MCP server，不用自己去搜
    3. 选择要用的服务器，按提示配置
  说明：
    · 后台会尝试从 GitHub 更新目录；失败时用内置列表，不影响使用

【MCP 信任管理（不再反复弹窗）】
  位置：MCP →「🔐 信任管理」
  作用：MCP 服务器每次启动都要确认一次，点过「永久允许」后就不再问。
  可以：
    · 看到每个服务器的状态和哈希
    · 「全部永久信任（不再弹窗）」一键授权全部
    · 「撤销全部信任」让它们重新询问
  ⚠️ 如果命令内容被改了（比如换了参数），哈希会变，会重新问你一次。
     这是防止命令被偷偷替换的保护，不是故障。

  能操作：
    · 输入目标创建任务
    · 查看每一步状态、耗时和错误
    · 开始 / 暂停 / 恢复 / 取消 / 重试失败步骤
    · 文件修改会显示 diff 预览
  其他入口（聊天任务卡片、活动中心「查看任务」、侧栏、命令面板）
  都会复用同一个任务中心，并自动切到你点的那个任务。

【启动只确认一次，但这些操作每次都问】
  会记住的：
    · 登录状态：这次登录过，下次直接进
    · 用户协议：同意过就不再弹
  每次都会问的（因为它们直接毁数据）：
    · 覆盖文件
    · 删除文件
    · 关机 / 重启
    · 执行命令
    · 自动更新部署

【窗口只开一个】
  任务中心 / 活动中心 / 命令面板 / 意见反馈 / 系统检测 / 电脑控制
  这些入口都是单实例：
    · 点多少次都只把已开的窗口放到前面
    · 关掉之后，下次点击才会重新打开
  关闭主窗口时，会先关掉所有子窗口，并停掉后台订阅和定时器。

十六、数据、备份与迁移
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【数据都在哪】
  data\config.json          主配置（模型、地址、开关、API Key）
  data\memory_cards.jsonl   记忆卡（一行一张）
  data\chats.db             聊天记录
  data\memory.json          长期记忆
  data\vectors.db           向量库
  data\_schema.json         数据版本登记表
  data\_migrations\         旧数据迁移前的自动备份
  data\logs\                日志（app.log / trunk.log 等）
  data\rules\rules.json     行为规则（63 条）
  data\workflows\           策划专家生成的工作流
  data\plugin_data\         插件自己的数据目录
  data\plugin_backups\      插件更新前的备份
  data\team\                团队集中配置
  backups\                  自动备份（可以删旧的）
  optional_libs\            可选依赖（可再装，不必分发）
  data\browsers\            浏览器内核（可再装，不必分发）

【旧数据会自动迁移】
  · 启动时检查 data\_schema.json 里的数据版本
  · 旧数据按 v0 → v1 → v2 逐级迁移
  · 迁移前先备份到 data\_migrations\backup_日期时间\
  · 迁移失败不会静默覆盖原文件
  · 想查原因：设置 → 系统 → 深度自检；或看 data\logs\trunk.log

【想恢复默认配置】
  数据都是文件，可以直接改：
    data\config.json        程序配置
    data\rules\rules.json   规则开关
  改坏了程序会自动补齐缺失项（不会崩），但建议先备份整个 data\。

【换电脑怎么搬】
  1. 关闭程序
  2. 整个文件夹拷过去
  3. 可以不拷这两样（省约 1.7GB）：
       optional_libs\（约 1GB）
       data\browsers\（约 700MB）
     到新电脑后按需再装
  4. 剩下必需的部分约 60~240MB
  注意：
    · 配置里的云端 Key 可能是加密的：换电脑 / 换 Windows 账号后
      可能解不开，需要重新填一次明文 Key
    · 带密码导出过记忆的话，导入时要用同一个密码

十七、出问题怎么查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【第一招：设置 → 系统 →「系统」深度自检】
  位置：高级模式 设置 → 系统 → 链接「系统」（深度自检）；
        或 Ctrl+K 搜「系统自检」「深度自检」。
  它会检查：
    语法、模块、数据版本、配置、能力、字体、云端连通性
  把问题直接列出来，按提示修。
  说明：
    · 云端那一行会真的发一次请求探测（结果缓存 5 分钟）
    · 用不了会写中文原因，健康分会扣 10 分

【第二招：设置 → 记录 → 日志中心】
  位置：高级模式 设置 → 记录 → 日志；或 Ctrl+K 搜「日志中心」。
  三个标签页：系统日志 / 运行日志 / 操作记录。
  ⚠️ 报错时把「运行日志」最后几十行复制出来，基本就能定位。
  也可以「导出日志包」，把生成的 zip 发过来。

【界面全白 / 花屏】
  先看底部状态栏有没有字，分两种：
    类型 A：底部状态栏有字，中间一片空白、没有按钮
      → 界面被清空（旧版本 bug，2026-10-21 已修复）
      → 更新到最新版本；源码启动请确认 gui\app_pyqt.py 是最新的
    类型 B：连按钮上的文字都是空白色块
      → Qt 找不到字体
      → 新版会自动注册 C:\Windows\Fonts 的微软雅黑 / 黑体 / Segoe UI
      → 仍不行：确认 C:\Windows\Fonts\msyh.ttc 存在，
        再看深度自检里「字体」那一行（Ctrl+K 搜「系统自检」）
      → 精简版 Windows 需要补装中文字体

  自查技巧：
    打开 data\logs\trunk.log，搜「[启动耗时]」。
    如果里面有「字体就绪(数字)」且数字大于 0，字体没问题，多半是类型 A。

【启动一直停在「正在启动…」】
  正常情况：新版先出窗口骨架、再装界面，约 1 秒内就会变成完整界面。
  一直停着：看 data\logs\trunk.log 最后几行有没有「启动失败」。

【一打开就弹好几个窗】
  正常顺序是：协议 → 登录 → 首次配置向导，一次只出现一个。
  如果你看到多个框叠在一起，说明版本较旧，更新后再用。

【发消息没反应】
  九成是模型没配好：
    1. 设置 → 系统 → 首次设置向导（或 Ctrl+K 搜「首次设置向导」）
    2. 或 Ctrl+K 搜「系统自检」，看差什么
    3. 看聊天区有没有红色提示

【连不上本地 Ollama】
  逐项检查：
    ① Ollama 装了没
    ② 它在不在运行（右下角托盘小羊驼图标）
    ③ 地址对不对（默认 http://localhost:11434）
    ④ 换了端口 / 虚拟机：见第三节「虚拟机连物理机」

【提示「Ollama 里没有 xxx 这个模型」】
  模型名和实际不符：
    1. 打开向导，点「重新检测」
    2. 从下拉框里选一个真实存在的模型
    3. 不要手打模型名

【语音功能点不动 / 说话没反应】
  可选依赖没装：
    1. 运行 scripts\install_optional.bat
    2. 重启程序
    3. 设置里看「可选功能状态」

【浏览器提示「内核没下载」】
  正常现象：
    1. 命令行运行 py -3 -m playwright install chromium
    2. 装完再试

【程序崩了 / 卡死】
  日志位置：
    data\logs\faulthandler.log   全部线程的 Python 栈
    data\logs\crashes.log        Python 层异常
  想要开发者看：设置 → 系统 → 意见反馈，会自动附带脱敏信息
  （系统信息 + 错误行 + 崩溃现场 + 日志路径，不含聊天内容）。

【云端 401 / 404 / 429】
  401  Key 不对或过期；也可能是加密 Key 换机器后解不开，
       去服务商后台重新复制明文 Key。
  404  地址不对；自定义时要填完整的 chat/completions 地址。
  429  额度用完或被限流，过一会儿再试或换模型。
  连不上  网络 / 代理问题。

十八、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Q1：它总说「我这个模型看不了图片」？
    A：当前模型不支持多模态。换支持看图的模型（如 Qwen-VL、GPT-4o），
       或在设置里切换到云端多模态模型。

Q2：它记错东西了怎么办？
    A：设置 → 记录 → 记忆可视化，找到那张卡片直接改或删。

Q3：想让它别记某些内容？
    A：在记忆可视化里删除对应卡片；
       也可以在聊天里明确说「这件事不用记」。

Q4：关闭设置页后，之前打开的窗口都没了？
    A：最新版已修正：设置页打开新功能时不再先关掉自己。
       关掉新窗口只关它自己，设置页仍然在。
       如果你还遇到「关一个全关」，说明版本较旧，更新后再用。

Q5：工作台写代码，为什么先弹 diff 不直接写？
    A：写盘前让你看一眼更安全。点「✓ 应用全部修改」才真正写；
       写前自动备份，「↩ 撤销本次修改」可以整体退回。

Q6：工作台输入了自然语言，为什么没开始写？
    A：① 先确认模型配好了；
       ② 确认按的是 Ctrl+Enter 或点「▶ 开始」；
       ③ 如果时间线显示「执行域：对话」，说明你加过 /chat。

Q7：代码写出来去哪了？
    A：应用后会自动打开对应文件；
       也可以在左侧资源管理器里双击查看。

Q8：能只聊天不写代码吗？
    A：可以，目标前加 /chat。

Q9：能操作电脑吗？
    A：可以，目标前加 /pc；危险操作仍会弹窗确认。

Q10：插件装不上？
    A：最常见是签名或 API 版本不兼容。
        官方插件带签名；第三方插件要符合 v1.0 标准。
        看安装提示里的具体原因。

Q11：MCP 每次启动都问我？
    A：去 MCP → 信任管理，点「永久允许」或「全部永久信任」。
        如果命令被改过，哈希会变，会重新问一次，这是正常的保护。

Q12：换电脑后云端 Key 报 401？
    A：配置里的 Key 是加密的，换 Windows 账号后可能解不开。
        去服务商后台重新复制一份明文 Key 填回来即可。

Q13：启动有点慢？
    A：正常是「先出骨架、再装界面」，全功能就绪约 1~1.2 秒。
        如果明显更慢，看 data\logs\trunk.log 里的「[启动耗时]」。
        需要旧行为（全部就绪才显示）可设环境变量 X6_BLOCKING_BOOT=1。

Q14：Windows 7 / 8 能用吗？
    A：不建议。主支持 Windows 10 / 11。
        Windows Server 部分功能可运行，但不是主要目标。
        macOS / Linux 只能部分聊天和文件功能，
        电脑控制、窗口操作、截图、剪贴板等桌面能力基本不可用。

Q15：Python 版本怎么选？
    A：3.10 / 3.11 / 3.12 支持；3.9 及以下不支持；3.13 尚未验证。
