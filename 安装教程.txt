小6智能体 - 安装教程
════════════════════════════════════════════════════════════

一、安装Python

1. 下载Python
   - 官网：https://www.python.org/downloads/
   - 支持版本：Python 3.10 / 3.11 / 3.12（推荐 3.12）
   - 不支持：Python 3.9 及以下；3.13 尚未验证

2. 安装Python
   - 双击安装包
   - ⚠️ 一定要勾选 "Add Python to PATH"
   - 点 "Install Now"

3. 验证安装
   - 按 Win+R，输入 cmd
   - 输入：python --version
   - 显示 Python 3.x.x 就成功了

二、安装依赖

**推荐**：直接双击项目根目录的 `install.bat` 
它会自动走清华镜像，把 5 个核心依赖装齐（PyQt5 / requests / numpy / cryptography / psutil）。

手动装也可以，**务必带国内源**（不带的话可能慢到以为卡死）：

   py -3 -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

如果提示找不到 `py`，把 `py -3` 换成 `python`。

三、下载小6智能体

1. 把整个小6文件夹放到电脑上
2. 建议路径：E:\xiaoliu
3. 不要放有中文的路径

四、启动程序

1. 双击 "启动PyQt.bat"
2. 或者打开cmd，输入：
   py -3 run.py

3. 第一次启动会弹隐私协议
4. 点同意，然后登录

════════════════════════════════════════════════════════════

常见问题：

Q: 提示 "python 不是内部命令"
A: Python没装好，重装时勾选 Add to PATH

Q: 提示 "缺少依赖"
A: 按提示 pip install 对应的包

Q: 程序闪退
A: 打开 "打开控制台.bat" 看错误信息
